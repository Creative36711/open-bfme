# Когда SVG, а когда генерация изображений

Правило для агента: **SVG — это разметка, а не картинка.** Его берут, когда
результат должен оставаться управляемым кодом; генерацию — когда нужен
материал, которого в коде нет.

## Главный тест (задайте себе первым)

> **При изменении размера результат должен остаться правильным?**

Если да — **SVG**. Если при увеличении всё расплывается и «мылится», значит
источник — растр, и рисовать его надо генерацией.

## Когда SVG

| Признак | Пример из нашей игры |
|---|---|
| Геометрия, а не материал | рамки, рамки кнопок, ромбы-указатели навигации |
| Должно жить в любом масштабе | иконки HUD, курсоры, маркеры на карте |
| Нужно менять цвет из кода | подсветка выбранного, «недоступно» — серый |
| Нужна точная пиксельная сетка | полоски HP, шкалы, прогресс, сетки |
| Текст и линии | подписи, разделители, схемы, диаграммы |
| Файл должен быть крошечным и диффиться | иконки в репозитории, `icon.svg` |
| Нужна анимация параметров | вращение, пульсация, заливка прогресса |

Хороший SVG в нашей игре — это не «нарисованная картинка», а **слой поверх
текстуры**: retail-стиль панелей уже несёт растр, а SVG добавляет чёткую
геометрию (рамку, ромб, шкалу), которая не мылится ни на 1080p, ни на 4K.

## Когда генерация изображений

| Признак | Пример из нашей игры |
|---|---|
| Материал: камень, металл, ткань, кожа | фон панели, пергамент, каменная плита |
| Свет, объём, тени, отражения | кнопка с фаской и бликом, подсвеченный тотем |
| Портрет или фигура | лица героев, юниты на карточках |
| Иллюстрация, атмосфера | экран загрузки, арт провинции, эмблема фракции |
| Органика — нельзя описать формулами | листья, трещины, дым, пламя |
| Нужна «дорогая» детализация | текстура брони, резьба по дереву |

## Рабочая связка: генерация + хромакей + SVG

Самый сильный приём — не «или-или», а конвейер:

```
генерация на #00FF00  →  cutout-chromakey.py  →  PNG с альфой  →  Godot
        ↑                                              ↑
   материал и свет                              SVG-слой поверх
                                            (рамка, шкала, подпись)
```

Генерация даёт **объём и материал**, хромакей вырезает фон, SVG добавляет
**чёткую геометрию и текст**. В Godot это один `Control`: `TextureRect` с
вырезанным PNG плюс дочерний SVG-слой.

### Почему жёстко #00FF00

Инструмент использует **строгий** зелёный ключ: пиксель — фон, только если
зелёный ярче 140, доминирует над остальными каналами и это **не** бирюза/циан
(`blue < 75% green`). Поэтому бирюзовые детали — вены, звуковые кольца,
патина — **не вырезаются**. В промпте генерации всегда просите чистый
`#00FF00` фон **без градиента и без теней на фоне**, иначе ключ не сработает.

## Чего не делать

- **Не рисовать SVG'ом то, что должно быть материалом.** Камень и металл,
  собранные из градиентов, всегда выглядят «пластиковой игрушкой» — это и есть
  та ошибка, когда «всё SVG».
- **Не генерировать то, что должно быть геометрией.** Иконку 16×16,
  собранную генерацией, нельзя перекрасить, она мылится и весит в сотни раз
  больше нужного.
- **Не генерировать текст.** Генераторы портят буквы; подписи — только в SVG
  или шрифтом движка.
- **Не генерировать без альфа-канала**, если элемент ложится на фон игры:
  сначала хромакей, потом проверка краёв на 100 % масштабе.

## Проверка перед сдачей

1. Увеличили в 4 раза — края остались резкими? (SVG — да, растр — нет.)
2. Перекрасили в коде — получилось? (Это возможно только у SVG.)
3. Посмотрели на 100 % — нет зелёного ореола по кромке? (Хромакей + despill.)
4. Вес: иконка SVG — единицы КБ, вырезанный PNG — сотни КБ. Оба законны,
   но для HUD предпочтителен первый.
